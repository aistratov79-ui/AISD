# Сортировки

## A. Сортировка выбором

Дан список целых чисел. Выведите все элементы этого списка в порядке невозрастания значений.

Решите эту задачу при помощи алгоритма сортировки выбором. Решение оформите в виде функции `SelectionSort(A)`.

### Формат входного файла

Одна строка — элементы списка через пробел.

### Формат выходного файла

Элементы списка в порядке невозрастания.

### Пример

**Входные данные**
```
1 4 2 3 4
```
**Выходные данные**
```
4 4 3 2 1
```

## G. Сортировка подсчётом

Дан список из *N* (*N* ≤ 2·10^5) элементов, которые принимают целые значения от 0 до 100. Отсортируйте этот список в порядке неубывания элементов.

Решение оформите в виде функции `CountSort(A)`. Сложность работы программы должна быть O(n). Использование встроенной сортировки (`sort`, `sorted`), алгоритмов пузырёк/quick sort/merge sort и других запрещено.

### Пример

**Входные данные**
```
7 3 4 2 5
```
**Выходные данные**
```
2 3 4 5 7
```

## I. Анаграммы

Слово называется анаграммой другого слова, если оно может быть получено перестановкой его символов.

### Формат входного файла

Два слова на отдельных строках (строчные латинские буквы и цифры, длина ≤ 255).

### Формат выходного файла

`YES`, если слова — анаграммы, иначе `NO`.

Сложность работы программы должна быть O(n). Использование встроенной сортировки и алгоритмов sort/quick sort/merge sort запрещено — решение через подсчёт частоты символов.

### Пример

**Входные данные**
```
sharm
marsh
```
**Выходные данные**
```
YES
```

## J. Число

Вася написал на длинной полоске бумаги большое число. Катя разрезала полоску на несколько частей, на каждой из которых оказалась одна или несколько идущих подряд цифр. Найдите максимальное число, которое могло быть написано на полоске перед разрезанием.

### Формат входного файла

Одна или более строк, каждая содержит последовательность цифр (не более 100 строк, каждая длиной 1–100 цифр).

### Формат выходного файла

Одна строка — максимальное число.

### Пример

**Входные данные**
```
2
20
004
66
```
**Выходные данные**
```
66220004
```

## K. Анти-QuickSort

Для сортировки последовательности чисел широко используется быстрая сортировка — QuickSort с выбором опорного элемента `a[(left + right) // 2]`. Требуется построить перестановку чисел от 1 до *N*, на которой такой QuickSort выполнит наибольшее число сравнений.

### Формат входного файла

Одно число *N* (1 ≤ *N* ≤ 70000).

### Формат выходного файла

Перестановка чисел от 1 до *N*.

### Пример

**Входные данные**
```
3
```
**Выходные данные**
```
1 3 2
```

## L. Такси

### Формат входного файла

Первая строка — N расстояний. Вторая строка — N тарифов.

### Формат выходного файла

Одно число — минимальная суммарная стоимость.

### Пример

**Входные данные**
```
10 20 30
50 20 30
```
**Выходные данные**
```
1700
```
